# Resume kit

This repository is harness-agnostic. You do not need Cursor skills, Cursor hooks, or a named model slug.

Read `AGENTS.md` and follow it for the whole session. Read `STYLE.md` before you write a bullet, an intro, or a note.

"Set me up", "/setup", "tailor this", and a pasted job description are the requests defined in `AGENTS.md`. Run `python doctor.py` before tailoring. If setup is incomplete, interview them. Do not tailor the placeholder.
